Additional sparse baseline hyperparameters
=========================================

These values correspond to the Variable TopK, L1SparseAutoencoder, and
JumpReLUSparseAutoencoder runs in stage4_arch_compare_results.csv.

Common configuration
--------------------

input_dim: 768
hidden_dim: 3072
hidden_multiplier: 4

Notes
-----

- Variable TopK uses an explicit Kmax. In this run, Kmax is equal to the nominal
  target for every point.
- L1SparseAutoencoder and JumpReLUSparseAutoencoder do not use an explicit Kmax.
- The nominal target is used to organize the sweep; sparsity is controlled by
  the regularization strength lambda for L1SparseAutoencoder and
  JumpReLUSparseAutoencoder.
- JumpReLUSparseAutoencoder was initialized with theta = 0.01 and bandwidth =
  0.05 for every point. Theta is represented as a learnable log-threshold in
  the model, so this is the initial threshold value.
